The out-of-band notification is now yours to choose.

Two kinds of session end fire while the lid is shut, the battery floor and Low Power Mode, and a screen notification behind a closed lid reaches nobody. awake can now call any executable you like with the message:

```
awake notify ~/bin/push-to-my-phone   # set it
awake notify                          # show it
awake notify --clear                  # back to screen only
```

Nothing is shipped for it and nothing is assumed: a push service CLI, an SMS gateway, a script that curls a webhook, anything that accepts one string argument. Unset by default. The call still goes out before the kernel flag drops, so the request leaves while the network is still up.

Also: the README now shows how to put a cup in your shell prompt, six lines of starship over `awake status --json`.
