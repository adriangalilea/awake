### Fixed

- **Double-clicking awake.app brings it back.** After quitting from the menu, opening the app from Finder, Spotlight or Launchpad did nothing visible. Now it starts awake again, with every claim it had.
- **Homebrew no longer warns about the cask.** Newer Homebrew versions warned on every `brew` command that the awake cask used a deprecated install hook. The cask now uses the current form, and installing or upgrading sets awake up exactly as before.
