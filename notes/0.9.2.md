The icon in glass, and an install count that no longer counts one Mac twice.

### Changed

- **The icon is drawn in glass.** On macOS 26 the cup takes the system's light, with depth and edges, in every appearance you can pick: dark, clear or tinted.
- **The daily update check sends a random install code.** awake makes it the first time it checks and keeps it in `~/.local/state/awake/config.json`. It is made of nothing about you or your Mac, and the server stores only a scrambled hash of it, so active installs are counted per copy instead of per network. `awake updates off` still stops the check.
