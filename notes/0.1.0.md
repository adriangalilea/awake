First public release.

awake keeps a Mac awake with the lid closed, on battery, with no external display. Every assertion-based tool gives up at exactly that point, and Apple's clamshell mode wants AC power and a monitor attached.

- Menu bar cup: right-click toggles at your last duration, left-click opens the menu. ⌃⌥⌘A does the same from anywhere, and is remappable with `awake hotkey`.
- A CLI that speaks the same state: `awake 2h`, `awake --until 23:30`, `awake -w <pid>` to stay awake exactly as long as a process lives, `asleep` to stop, `awake status --json` for scripts.
- A battery floor, 15% by default, that ends the session and lets the Mac sleep even if you insisted. Low Power Mode does the same unless you forced it.
- Sessions survive a daemon crash and a reinstall, and never survive a reboot.
- One authorization prompt, once, for a sudoers rule covering exactly two commands. `awake grant --remove` takes it back.

Requires macOS 26.
