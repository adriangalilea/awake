### Added

- **A daily update check.** Once a day awake fetches its own feed at awake.untitled.garden and, if a newer version exists, says so once on screen and points at `brew upgrade --cask awake`; `awake status` shows the same nudge. The fetch carries nothing: no identifier, no usage data. It doubles as the only signal the garden has of how many Macs run awake (a salted, non-reversible hash of the day's caller IP, never the IP). `awake updates off` stops both.
- **The download button on awake.untitled.garden** goes through the garden's own counted path instead of GitHub.
