awake ships its agent skill: `awake skill install` teaches Claude Code and Codex to keep your Mac awake the right way.

### Added

- **The agent skill ships with the app.** `awake skill install` links it into Claude Code and Codex, whichever of the two is on your Mac. It teaches the agent to hold the Mac awake for exactly as long as its work runs, to ask you before it keeps going with the lid shut, and never to reach for `caffeinate`, which dies when the lid closes. The link points into the app, so upgrading awake upgrades the skill. `awake skill` shows where it is installed, `awake skill remove` takes it away, and deleting the app removes it too.

### Changed

- **A new icon.** The cup in perspective, resting in its saucer, seen the way the menu bar glyph sees it.
